# On-Prem
This section covers managing and modernizing Microsoft workloads that run outside AWS, such as on VMware, Hyper-V or physical servers. Guides use AWS services like [AWS Systems Manager hybrid activations](https://docs.aws.amazon.com/systems-manager/latest/userguide/activations.html) to operate on-premises Windows Server alongside your AWS resources.
